# 交易追踪 - 数学优势系统 v2.4

基于 R 值（风险单位）的股票交易记录与胜率分析工具。

## 核心功能

- **R 值止盈计算**：自动计算 1R/2R/3R/5R/10R 止盈位
- **R 值宽容度归类**：实际盈亏在标准刻度的 ±N% 内自动归类（如 0.9R~1.1R 都算 1R）
- **实际盈亏金额**：基于真实股数 × 价格差计算
- **编辑交易记录**：点击「编辑」修改任意字段，持仓中/已平仓均可修改
- **实时持仓估值**：支持手动输入当前价或接入 API 自动刷新，显示浮动盈亏(R/元)
- **权益曲线**：Canvas 绘制的资金走势图
- **动态仓位建议**：根据总资金自动建议股数
- **设置面板**：勾选字段、看板组件、R值宽容度、实时行情源、自动同步开关
- **扩展字段**：策略标签、时间框架、情绪评分、计划止盈、交易笔记
- **月度汇总**：按月的胜率、盈亏、平均 R 统计
- **GitHub Gist 云端同步**：跨设备数据同步，支持自动拉取/推送

## 部署到 Vercel

1. 把本仓库 push 到 GitHub
2. 登录 [Vercel](https://vercel.com) → Add New Project → 导入仓库
3. Framework Preset 选 **Other**
4. Deploy

## 配置

1. GitHub → Settings → Developer settings → Personal access tokens → **Tokens (classic)**
2. Generate new token → 只勾选 **gist** 权限
3. 在网页配置面板填入 Token，首次同步留空 Gist ID 自动创建
4. 在设置面板开启"自动同步"，实现跨设备实时

## 数据存储

- **本地**：浏览器 localStorage（交易记录、设置、持仓价格缓存）
- **云端**：GitHub Gist（JSON 格式，包含 trades + settings）
- **自动同步**：页面加载自动恢复、交易变更自动推送
